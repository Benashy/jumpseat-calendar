FDP lookup workflow

Time reference: the LTOT calculator uses Zulu, while FDP table start times use the applicable local or reference report time.

1. Reporting in a time zone no more than 2 hours from London

Remain acclimatised to London. Use the departure-airport local report time with Table 2. Table 1 is not required.

2. Reporting in a time zone more than 2 hours from London

Use Table 1 with the time-zone difference and total elapsed time since the first London report to establish whether the crew member is in state B, D or X.

3. Select the FDP
  • B: use Table 2 with London time.
  • D: use Table 2 with the local report time where the next duty starts.
  • X: use Table 3.

B, D and X examples

B usually means the time-zone change has not been large enough, or the crew member has not been there long enough, to move the body clock away from the departure time zone. Example: after a short stay in New York, the body clock may still effectively be on London time, so London time is used when entering Table 2.

D means the crew member has had time to acclimatise to where the next duty starts. Example: after long enough in New York, use New York local report time with Table 2.

X usually follows a larger time-zone change without enough time to fully acclimatise. The crew member is between time zones, so Table 3 is used. Table 3 is generally more restrictive.

How to count elapsed time

Start the clock at the first report in London for the current rotation and stop it at the subsequent down-route report. Include the outbound FDP and all intervening rest or layover time.

The clock resets when the rotation ends and the next rotation begins following rest at home base.

New York example: after initially reporting in London, operating to New York, resting, and subsequently reporting in New York, use the total elapsed time from the London report to the New York report. If the applicable time difference is 5 hours, use the 4-6-hour row: less than 48 hours gives B, 48 hours to 71 hours 59 minutes gives X, and 72 hours or more gives D.

For a rotation involving further duties after rest periods in several different time zones, confirm the acclimatisation state using the full OMA process or Global Ops.

LTOT Guidance

OMA 7.11.1

The Latest Time of Pushback is a soft limit; if exceeded, then all reasonable efforts should be made to depart before the Latest Time of Take-off.

The Latest Time of Take-off is a hard limit; if it is likely to be exceeded, a return to stand or an alternative plan, such as an intermediate diversion, must be implemented.

OMA 8.28.18

When calculating an LTOT, it is important to ensure the calculation uses realistic and achievable timings. Should any delay occur after an LTOT has been calculated and agreed with Global Ops, the flight can continue provided one or more of the following factors are met:

  1. The delay has resulted in a reduction in the flight time e.g. change to a more favourable runway, new routing and the new flight time results in an on chocks time less than max FDP.
  2. The delay is less than 5 minutes, and there is a realistic possibility the routing would enable this delay to be eradicated.
  3. The original LTOT plan had extra contingency for unforeseen circumstances and that contingency accounts for all or part of the delay.

If any of the above factors are encountered, the revised LTOT must still be realistic and achieve the latest on chocks time. Furthermore, once airborne and during a low workload situation the crew should contact Global Ops via ACARS (.OPC | .LHRWWBA) informing them of the adjusted timings. If during the flight, the ‘on chocks’ time is projected to exceed the maximum allowable FDP, then all options must be explored to mitigate this exceedance. This may include diverting to an airfield where an on-chocks time is within the maximum allowable FDP.

My interpretation

Before departure, there must be a realistic and achievable plan that ensures the flight will remain within the maximum FDP. If unforeseen circumstances after departure mean an FDP exceedance becomes likely, the commander must take all reasonable steps to mitigate it and make a justified operational decision based on the circumstances, which may or may not include diversion.
